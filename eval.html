BackTrack · eval

Score the transcription against a real vocal dataset (mir_eval metrics).

Dataset

Pick a folder of vocal audio and its reference annotations (matched by filename). Supported: Vocadito / MIREX F0 CSV ("time,freq"), Vocadito note CSV ("start,end,pitch"), MIR-1K .pv. Nothing is uploaded — analysis runs in your browser. Note-level F-measures are the fair score for a note transcriber; frame RPA runs lower because note transcription intentionally omits glissandi a continuous-F0 reference includes.

No dataset is bundled with this site. Vocadito is ~74 MB and separately licensed, so Run Vocadito (auto) only works against a local checkout with the dataset placed in vocadito/ (regenerate vocadito/manifest.json with tools/build-eval-manifest.ps1; add ?run=vocadito to run on load). Without it, use the file pickers above with your own audio + annotations — or just press Self-test metrics, which needs no dataset at all.
